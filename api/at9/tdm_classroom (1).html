Authentification - checkuser()
La fonction checkuser($login, $pass) dans Tstutents.php execute la requete :

SELECT * FROM utilisateur WHERE login='$login' AND pass='$pass'

Elle utilise rowCount() pour compter les resultats. Si $nbr == 0 alors erreur, sinon header("Location:save.php").

Attention : Ce code est vulnerable aux injections SQL. En production, utiliser des requetes preparees avec PDO::prepare().

Insertion - AddStudent()
La methode AddStudent($nom,$prenom,$ville,$phototem,$photodes) execute :

INSERT INTO student(nom,prenom,ville,photo) VALUES('$nom','$prenom','$ville','$photodes')

Ensuite move_uploaded_file($phototem, $photodes) deplace la photo uploadee dans le dossier /pics/.

Note : La methode Dataaccess::majour($req) wrappe PDO::exec() pour les requetes d'ecriture.

Pagination - GetStudentsPagination()
La methode utilise la requete :

SELECT * FROM student LIMIT $offset, $limit

Ou $limit = 3 et $offset = ($page - 1) * $limit.

La methode GetTotalPages() calcule : ceil(totalStudents / $limit).

Note : On boucle avec while($row = $cur->fetch()) sur l'objet PDOStatement retourne.

AJAX HTML - GetStudentsByCity()
Le combo est rempli par PHP avec GetCities() qui execute :

SELECT DISTINCT ville FROM student

Lors du changement de selection, jQuery AJAX appelle searchstudents.php?ville=... qui retourne du HTML genere par GetStudentsByCity($city).

Pattern : $.ajax({url, method, data}) suivi de .done(function(rep){ $("#resultat").html(rep); })
